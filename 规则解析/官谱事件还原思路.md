# 官谱事件还原思路

可玩音符（点击 / 长按 / 连打 / 齿轮 / 幽灵）已经能从 `MusicData` + `NoteConfigData.ibms_id` 进 MDM。缺的是 **演出与脚本**，不是 `StageInfo.sceneEvents` 那条残缺 TypeTree。

## 事件实际写在哪

UnityPy 读到的 `sceneEvents` 只有 `uid`（如 `SceneEvent/10`），没有 `time` / `value`，不能当时间轴。

真正带时间的事件和音符同一份 SerializedBytes：`tick` + `note_uid`。抓取 tick 可能含**该设备游戏延迟**。落事件 / `0S` 前自动检索整格 D：`D = n × (240/BPM/192)`。游戏设置里的 0.35 在 BPM160 是 **45格 = 0.3515625s**（槽长 0.0078125s），不要减 0.35。再 `tick−D` 吸 192 槽；不要用带延迟的 1.6640625s。`--capture-delay auto|0|45格|0.3515625`。键已在格子上时，用最早键扣完后落在拍上（拍内槽=0）决胜。

## 分类（模板已有 ibms，与编辑器调色板同一套键）

| NoteType | 含义 | 典型 ibms | BMS 通道 |
|----------|------|-----------|----------|
| 1–8 | 可玩键 | 01 / 0F / **0G / 16 / 17** / 21 / **11**… | 13/14 或 53/54 |
| **0 None** | Boss 演出（入场/退场/阶段） | **1A–1H** | **15** |
| **9 SceneChange** | 切场景 | **1O–1W** | **15** |
| 10 / 11 | Auto 开/关 | 2Y / 2Z | 15 |
| 12 / 13 | 隐藏/显示音符 | 1J / 1K | 15 |
| 14 / 15 | 隐藏/显示 Boss | 1L / 1M | 15 |
| 16 / 17 | 隐藏/显示背景 | 25 / 26 | 15 |
| **≥18**（JSON 扩展，dump 枚举未列全） | 滚动、暗角、闪光、滤镜等 | 27–2X、CM… | 15 |

规则：**type == 0 或 type ≥ 9，且 ibms 非空 → 事件**；没有 ibms 的 type 0 占位丢掉。

编辑器 `BmsReader`：通道 15 只有 Event、没有空中/地面 → `Kind=event`。不必改编辑器。

## 写出

```
#01515:1A          Boss 入场
#01915:1Q          切场景 城堡
#02515:1S          切场景 糖果
```

同一格多个事件：通道 15 叠行（`write_bms._place_tick` 已支持）。不写进 13/14，否则会被当成键。

## 不要从 sceneEvents / 08 猜变速

- mopemope 的 `MusicInfo.bpm = 100～200` 是曲库展示，网格仍用 `StageInfo.bpm=100`。
- 官谱模板里 **没有** `0O–0W` 画面流速键，也 **没有** 飞近通道 `0S`（飞近在 uid `speed`）。当前转录压成 **`0S` 台阶** + 同刻输家 `chart.json`（进 zip；CustomAlbums 忽略）。不要用 GitHub 旧方案的 `0O` 表达飞近。画面滚动是 `27/28/29`。
- 同轨长按内丢掉的是长按/连打中间刻；`0H`/`23`/`0D` 等条内键要保留。Boss 齿轮 `18` 写在长按头类型里仍可能被丢掉。
- `dialogEvents` TypeTree 里经常没有，对白不进自制 MDM。
- 抽检 121 张官谱：可玩键时间都落在标称 BPM 的 192 格上，**通道 08 没有可还原的变速点**。听感加倍是音符变密，不是 `#BPMxx`。

## 落地顺序

1. 转换器不再丢 type 0 / ≥9，事件进通道 15（本步）。
2. 打开 MDM，事件轨应出现切场景、Boss 入场、显隐。
3. 暗角/闪光等同键已在 `BmsLabels`；没有标签的 ibms 仍按 2 字符 id 显示。
4. 通道 08 变速仍不做，直到有带时间的 BPM 段权威源。

## Unity 怎么播这些事件

通道 15 与可打 Boss 键由 `PlayClient` 的 `BossTimeline` 消费（细则只维护 `mdm物件转化词典.md` §2.1）：

- `1A` 入场；`1B` / 连打 `17` 退场后本体不在场。夹在 `1A` 与 `1M` 之间不到 1s 的 `1B` 不算退场。
- `1L` 隐藏；`1M` 只解除 1L，**不能**把 1B/17 之后的本体拉回来。要等退场结束之后的 `1A`。
- `1C`/`1E` 只是远端攻击脚本：谱面还在藏/退时 **不要** 用弹幕 `13/14/15` 或 `1E` 把 x01 召回。
- 可打：近战 `11/12`（冲刺后打中 `hurt` 击退）、连打 `16`（有 `multi_atk_48` 前置，打完回场）、有长度的 `17`（判定瞬间瞬移到连打位，打完往右离场；点长直接退场）、弹幕 `13/14/15`（飞近 + 本体 `far_atk_*`）。`11/12/16/17` 不要再画飞近。
- 折叠顺序：先按 hidden / leave / shown 决定在不在场，再叠 mash / melee / shot。`1A` 之前有 `1A` 脚本的谱，本体不自动待机。
